# Albumschere

Fotografierte Albumseiten rein, einzelne Fotos als JPG raus.

- Erkennt die Fotos auf einer Albumseite automatisch (auch schräg aufgeklebte), Rahmen von Hand korrigierbar
- Dreht die ganze Seite automatisch in die richtige Lage
- Schneidet perspektivisch entzerrt aus dem Original in voller Auflösung aus (JPG, Qualität 95)
- Dateinamen: `PRÄFIX_S01_F01.jpg` (Präfix frei wählbar, Standard: heutiges Datum)
- Speichern in Fotos-App (iPhone), Dateien/Downloads oder einen Ordner
- Läuft komplett im Browser, keine Daten verlassen das Gerät; als App installierbar (PWA), offline nutzbar
